# 奶蛙去哪了？— 上學大作戰

一款以大學宿舍與校園為背景的互動式尋物小遊戲。玩家原本只是想準時出門上課，卻得先找齊亂放的隨身物品，接著還要一路追捕不想上學、四處亂跑的奶蛙！

## 遊戲故事

早上快遲到了！主角慌忙在宿舍尋找手機、鑰匙、無線耳機和行動電源。好不容易收拾好，卻發現奶蛙失蹤了。你必須在宿舍、公共區域及校園尋找躲起來的奶蛙。每次找到他，他又會找藉口跑走……最後還有意想不到的結局。

## 遊戲特色

- **四個關卡**：宿舍尋物、宿舍找奶蛙、公共區域追逐、校園最終搜尋。
- **故事對話**：透過主角與奶蛙的逗趣對話串起關卡。
- **隨機藏身位置**：部分目標每次挑戰出現的位置可能不同。
- **限時挑戰**：每關 90 秒，時間到可以重試。
- **提示系統**：每關可使用兩次提示，短暫標示目標。
- **滑鼠與觸控支援**：直接點擊場景裡的物件或奶蛙。

## 如何遊玩

1. 開啟遊戲，點選「開始冒險」。
2. 閱讀或跳過故事對話，觀察中央場景。
3. 點擊任務清單指定的物品或奶蛙。
4. 在時間內完成任務，觀看過關對話並前往下一關。
5. 全部通關後可以重新遊玩。

## 遊戲畫面與技術

本作品使用 **HTML、CSS、JavaScript** 製作，圖片素材為 PNG，無須帳號或後端伺服器，可透過 GitHub Pages 遊玩。

## 在本機執行

下載本專案後，直接以瀏覽器開啟 `index.html` 即可。請保留 `images/` 資料夾及圖片的相對路徑。

## GitHub Pages 發布

將 `index.html` 與 `images/` 上傳到 GitHub Repository 根目錄，於 **Settings → Pages** 選擇 **Deploy from a branch**、`main` 和 `/(root)`，儲存後等待網站發布。

## 素材與專案結構

```text
index.html              # 遊戲主程式
images/                 # 背景、物品與奶蛙角色 PNG 素材
build_single_html.py    # 選用：產生單一 HTML 交作業版本
README.md               # 遊戲介紹
```

若想更新角色或物品圖片，可用同名 PNG 覆蓋 `images/` 中的檔案。替換不同長寬比的圖片時，可能需要調整遊戲裡的物件尺寸及位置。
